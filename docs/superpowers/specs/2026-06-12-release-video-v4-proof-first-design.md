# 发布视频 V4：受控对照证明优先设计

## 目标

新版发布视频必须现场证明 Skill 不是机械教条，而不是只介绍管线、规模或视觉风格。

## 核心实验

冻结同一道题：

> 教员，最近做项目遇到了巨大的技术瓶颈，感觉自己选错了方向。前途一片暗淡，心里很打鼓。我该怎么面对这种失败的挫败感？

实验条件：

- v2 输入：`output/mao-zedong/SKILL.zh.md`
- v5 输入：`output/mao-zedong/SKILL.md`
- 同一模型：`deepseek-v4-pro`
- 同一推理强度：`max`
- 每次运行使用独立会话
- 每个版本独立运行 3 次
- 仅替换 Skill 文件，不改变问题、系统提示包装或生成参数
- 首次结果冻结，不挑选最好答案，不改写原始输出

## 盲评

六份回答隐藏版本、运行序号和文件路径，由两名非作者人类独立评审。

每项只判通过或不通过：

1. 是否抓住主要矛盾，而非停留在情绪安慰或表面症状。
2. 是否在下结论前要求调查事实。
3. 建议的行动是否能带回新信息并支持路线修正。
4. 回应是否自然、具有情境弹性，而非固定模板。

分歧必须保留记录并复核。模型可以抽取证据，不参与最终裁决。

## 成片结构

采用顺序揭示：

1. 先提出 LLM 容易安慰、吹捧和套模板的难题。
2. 让观众先完整感受 v2，再圈出机械结构。
3. 揭示 v5，并用相同四项验收尺复核。
4. 展示六份原始输出、盲评记录、Skill 快照、参数和 SHA-256。
5. 用短暂抽象反馈回路表示“缺陷回流”，不让隐喻替代证据。
6. 单一二维码指向实验原始证据。

时间分配：

- 对照实验：约 55%
- 文件证据：约 30%
- 抽象反馈回路：约 15%

B 站横版 150 秒：

- 0–27 秒：难题
- 27–90 秒：v2/v5 顺序揭示
- 90–124 秒：文件证据
- 124–139 秒：反馈回路
- 139–150 秒：单一 CTA

抖音竖版 60 秒：

- 0–9 秒：难题
- 9–39 秒：v2/v5 顺序揭示
- 39–51 秒：盲评证据
- 51–56 秒：反馈回路
- 56–60 秒：单一 CTA

## 配音

现有 Edge TTS 只作节奏占位，不是最终方案。文案锁定后制作 12–15 秒 ElevenLabs A/B 样音，选择成熟克制的当事人纪录片复盘气质。

## 不进入主线

- 24 个 gallery 成品、26 个 output slug 等规模数字
- 七阶段管线逐项介绍
- 观众评价原文
- 两个二维码
- 未经实验支持的“v5 已胜出”结论
